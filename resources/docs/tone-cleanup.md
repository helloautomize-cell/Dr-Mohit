# Tone & AI-fingerprint cleanup (Phase 9)

Rules applied to all user-facing text so the site reads like a hospital wrote
it — and so rendered copy carries none of the punctuation patterns scanners
associate with machine-generated text.

## Enforced rules

1. **No em/en dashes in rendered text.** `—` (U+2014) and `–` (U+2013) do not
   appear in page copy, UI strings, alt text or metadata. `seo-check.mjs`
   hard-fails if any rendered route contains one. (Code comments are source,
   not output — they may keep them.)
2. **No superlatives or guarantees** (NMC advertising rules): no "best",
   "No. 1", "first-ever", "100%", "painless", "zero infection", "guaranteed",
   "completely safe". The old WordPress copy used several — none carried over.
3. **No AI-filler tone:** no "In today's fast-paced world", "Delve into",
   "Furthermore/Moreover" chains, "It's important to note", "Look no further",
   "world-class", "state-of-the-art", "cutting-edge", "revolutionary".
4. **Plain words over jargon** — the site explains "gathiya" before
   "osteoarthritis" and "motiya" before "cataract" because that is what
   patients search and say.
5. **Honest uncertainty:** unverified facts render as visible `[CONFIRM]`
   chips (ConfirmValue component) — never silently asserted, and never in
   JSON-LD.
6. **Compliance holds:** no testimonials, no before/after imagery, no
   fee discounts, illustrations labelled "Illustration only".

## What was cleaned in this pass

- `messages/en.json` — "Not sure — need guidance" → "Not sure, need guidance";
  booking-error "below — please call" → "below. Please call".
- `messages/pa.json` — same two strings de-dashed in Punjabi.
- Verified `resources/content/site-content.en-pa.json` already carries **zero**
  em/en dashes (earlier phase had cleaned it).
- `seo-check.mjs` now scans rendered `innerText` per route so regressions
  fail the audit.

## Where new copy must hold the line

- Booking-form strings (`messages/*.json`, `booking.*` keys)
- Alt text in `lib/image-slots.ts` / `scripts/alt-text.json`
- Meta titles/descriptions — exported to `titles-descriptions.csv` by
  `pnpm seo-check` for client review.
- `llms.txt` / `llms-full.txt` / `/md/` mirrors — generated by
  `scripts/gen-seo-files.mjs` from the same copy source, so they inherit the
  cleanup automatically.
